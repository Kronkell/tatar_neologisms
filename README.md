# Сколько попарных сравнений заменяют признаки объектов

**Автор:** Минабутдинов Камиль, ВМК МГУ, кафедра ММП

Априорный прогноз того, во сколько раз признаки объектов сокращают число попарных сравнений, нужных людям для ранжирования. Модель — иерархическая модель Брэдли–Терри; в лапласовом приближении получены формула экономии, спектральные границы для произвольного плана опроса и нижняя оценка риска, предложен уточнённый прогноз методом Монте-Карло. Проверка — на синтетических данных и на человеческих оценках сложности английских слов. Прикладная мотивация — выбор татарских замен русских заимствований по мнению носителей.
